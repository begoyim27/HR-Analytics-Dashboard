HR Analytics: Employee Career Growth & Salary Insights
1. Project Overview
This project focuses on analyzing human resources data to uncover trends in employee promotions, salary distributions, and departmental structures. By combining Python for data preprocessing and Power BI for interactive storytelling, I transformed raw HR data into actionable business insights.

2. Tech Stack
Data Cleaning & Manipulation: Python (Pandas, NumPy)

Data Visualization: Power BI Desktop

Analysis Language: DAX (Data Analysis Expressions)

Data Source: Excel / CSV

3. Key Business Questions Addressed
Career Mobility: What percentage of employees have changed their positions?

Compensation: How is the salary distributed across different job levels (Junior, Mid, Senior, Lead)?

Departmental Growth: Which departments show the highest rate of internal promotions?

Hiring Trends: How has the company's headcount evolved over the years?

4. Key Features of the Dashboard
KPI Cards: Real-time metrics showing the percentage of position changes vs. no changes.

Salary Histogram: A deep dive into pay scales to identify compensation clusters.

Departmental Pie Chart: A visual breakdown of staff distribution by business unit.

Interactive Filters: Users can slice the data by Department, Hire Date, or Position Level.

5. Repository Structure
HR_Dataset_Analysis.pbix: The main Power BI dashboard file.

data/: Folder containing the cleaned HR dataset.

scripts/: Python scripts used for initial data cleaning (handling missing values, formatting dates).

screenshots/: Preview images of the final dashboard.
6. How to Use
Clone this repository or download the .pbix file.

Open the file using Power BI Desktop.

Interact with the visuals to explore different HR metrics.
